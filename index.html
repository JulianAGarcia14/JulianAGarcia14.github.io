Video measurement · QoE

An independent witness for playback quality

A streaming client reports its own startup time, so checking it against its own telemetry proves nothing. I built a measurement system that watches the actual video output of each device and times what the customer sees.

  • Measures time-to-first-frame, rebuffering, bitrate, bandwidth, abandons and fatal errors on every device family
  • Network impairment via switch-port policing to induce real-world conditions
  • Showed a fleet-wide startup metric understated what customers experience by 1-3 seconds

LLM agents · Tool use

A lab agent that runs tests, watches devices and proposes fixes

A tool-use agent on AWS Bedrock with 63 tools: it can run a test, read a device's live video and telemetry, and diagnose a failure. Fixes go through a gated path: diagnose, propose, typed confirmation, execute, audit, verify.

  • Risk graded by what a change touches, with rate limits counted from the audit log
  • Smaller models for mechanical steps, larger ones only where they pay off
  • Designed the tool-calling architecture of the team's support bot, built with an intern I mentored

Full-stack platform

One operations surface for a 270-device lab

The team had four separate tools for scheduling, accounts, debugging and device state, and none of them belonged to it. I built a single platform for all of it, with no spec and nobody asking for it, and it became the team's daily driver.

  • Job scheduler, live device state, in-browser live video of any device, statistics and reports
  • Lab monitor raised reachable devices from 4 to 37 and cut open faults from 39 to 6
  • 111 React components, 8 CDK stacks; authored 82% of 1,400+ commits

AI-native engineering

A multi-agent workflow for parallel engineering

I run many investigations at once, each as its own agent with its own workspace. A coordinating agent watches all of them, and a shared knowledge base keeps what each one learns, so later work starts from what earlier work found.

  • Agents from more than one model family share the same tools, skills and knowledge
  • Dashboard and MCP tools show live state and warn when two agents edit the same file
  • Phone access and notifications when an agent finishes or needs a decision

Ads · Audience measurement

Validating ads and audience measurement end to end

Audience measurement is reported to outside partners, so mistakes in it cost money. I automated validation of audience-measurement and ad-insertion telemetry across several datasets that update late, for an ads team and a program team at once.

  • Nightly checks of every required telemetry field on every device family
  • A cause attached to every disagreement, rather than a pass/fail per night
